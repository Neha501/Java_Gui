# Employee Payroll Management System

## Features

-   Single JFrame Java Swing application
-   Employee information
-   Department selection
-   Automatic HRA, DA and Tax calculation
-   Net salary calculation
-   Salary slip dialog
-   Payroll history using JTable

## Technologies

-   Java
-   Swing
-   AWT

## Run

``` bash
javac EmployeePayrollSystem.java
java EmployeePayrollSystem
```
