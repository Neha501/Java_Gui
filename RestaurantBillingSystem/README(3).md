# Restaurant Billing System

## Features

-   Modern light-themed Java Swing application
-   Single JFrame
-   Customer details
-   Food item selection
-   Quantity selection
-   Automatic subtotal calculation
-   5% GST calculation
-   Billing history using JTable
-   Bill generation confirmation

## Technologies

-   Java
-   Swing
-   AWT

## How to Run

``` bash
javac RestaurantBillingSystem.java
java RestaurantBillingSystem
```
