# Library Management System

## Features

-   Modern light-themed Java Swing application
-   Single JFrame
-   Student details
-   Book selection
-   Issue duration selection
-   Automatic library fee calculation
-   Book issue history using JTable
-   Issue confirmation dialog

## Technologies

-   Java
-   Swing
-   AWT

## How to Run

``` bash
javac LibraryManagementSystem.java
java LibraryManagementSystem
```
