# Movie Ticket Booking System

## Features

-   Modern light-themed Java Swing UI
-   Single JFrame application
-   Movie selection
-   Seat category selection
-   Show time selection
-   Ticket quantity
-   Automatic subtotal, GST and total calculation
-   Booking confirmation
-   Booking history table

## Technologies

-   Java
-   Swing
-   AWT

## How to Run

``` bash
javac MovieTicketBooking.java
java MovieTicketBooking
```
