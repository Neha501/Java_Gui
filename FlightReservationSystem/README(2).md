w# Flight Reservation System

## Features

-   Single JFrame Java Swing application
-   Modern light UI
-   Passenger information
-   Source and destination selection
-   Airline and seat class selection
-   Automatic fare and tax calculation
-   Booking history table
-   Reservation confirmation

## Technologies

-   Java
-   Swing
-   AWT

## How to Run

``` bash
javac FlightReservationSystem.java
java FlightReservationSystem
```
